# System76 / COSMIC trademark

System76 confirmed that this project may use COSMIC™ while it complies with
the [COSMIC trademark policy](https://github.com/pop-os/cosmic-epoch/blob/master/TRADEMARK.md).
Their reply was:

> You can use COSMIC™ as long as you are in full compliance with
> https://github.com/pop-os/cosmic-epoch/blob/master/TRADEMARK.md

Copyright in the brand artwork stays with System76, Inc. The policy is what
allows the name and the logo.

## Name

The policy lets a third-party applet call itself “for the COSMIC™ desktop”.
This project uses that wording, the `cosmic-ext-` package name, and an app id
outside the official `com.system76.` prefix. The name says which desktop the
applet runs on. It is not official COSMIC software, and System76 has not
endorsed it.

## Logo

The policy says the COSMIC logo is to be used as provided: its colours,
proportions and overall design.

`resources/icons/cosmic-logo.svg` is the official colour mark: the orange
gradient (`#ffae02`, `#ff972a`, `#fe7e57`) and the white wordmark, fitted to a
square icon canvas for the panel button.

`resources/icons/cosmic-logo-mono.svg` is the same drawing in grey, used when
the panel icon is set to monochrome.

Source artwork: [`system76/brand`](https://github.com/system76/brand),
`COSMIC branding/cosmic logo white + gradient mark.svg`, revision
`bed1fd3fd39d3f3371c57f15878195888c617777`.
